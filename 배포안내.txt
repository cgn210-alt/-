================================================================
  경북 상주 국내아웃리치 앱 — 최초 배포 안내
================================================================

이 앱은 Google Sheets + Apps Script를 백엔드로 사용합니다.
설치 없이 스프레드시트 하나로 여러 사람이 동시에 출석/방문 체크를
실시간으로 공유할 수 있습니다.

▶ 소요 시간: 약 5분

★ 이미 STEP 1~4를 완료해 웹 앱 URL을 발급받으신 분은 ★
  1) Code.gs 최신 내용을 기존 Apps Script 프로젝트에 다시 전체
     붙여넣기 → 저장
  2) seedDeployment 함수를 한 번 실행 (아래 STEP 2-1 참고)
  3) [배포] → [배포 관리] → 기존 배포 옆 연필(✎) 아이콘 →
     버전: "새 버전" 선택 → [배포]
     (※ "새 배포"를 새로 만들면 URL이 바뀌어 앱 설정을 다시 입력
       해야 하니, 반드시 "새 버전"으로 기존 배포를 갱신하세요.)

================================================================
  STEP 1. 새 Google Sheet + Apps Script 프로젝트 만들기
================================================================

1) https://sheets.google.com 접속 → 빈 스프레드시트 새로 만들기
   이름 예시: "상주아웃리치_출석부"

2) 메뉴 [확장 프로그램] → [Apps Script] 클릭
   → 새 창(script.google.com)이 열립니다.

3) 기본으로 열려 있는 코드(Code.gs)를 전체 선택(Ctrl+A) 후 삭제

4) 이 폴더의 Code.gs 파일 내용을 전부 복사해서 붙여넣기

5) 저장 (Ctrl+S)

================================================================
  STEP 2. 초대자 명단 초기 데이터 넣기 (최초 1회만)
================================================================

1) Apps Script 편집기 상단의 함수 선택 드롭다운에서
   "seedRoster" 선택

2) ▶ 실행 버튼 클릭

3) 처음 실행 시 "권한 검토 필요" 팝업이 뜨면
   → 계정 선택 → [고급] → "프로젝트로 이동" → 허용

4) 실행 완료 후 원래 스프레드시트로 돌아가면
   "초대자명단" 시트가 자동 생성되고 56명 명단이 채워져 있습니다.

   ⚠ 시트의 19번 행은 원본 인쇄물이 흐려 이름을 정확히 판독하지
     못해 [확인필요]로 표시되어 있습니다. 원본 9.초대 페이지(16p)를
     보고 직접 이름을 채워 넣어 주세요.

   ⚠ 현장에서 명단에 없는 방문객이 오시면 앱의 "+ 현장 등록" 기능을
     쓰거나, 이 시트에 직접 행을 추가해도 됩니다.

================================================================
  STEP 2-1. 인원배치(버스/팀별) 초기 데이터 넣기 (최초 1회만)
================================================================

1) Apps Script 편집기 상단의 함수 선택 드롭다운에서
   "seedDeployment" 선택 → ▶ 실행

2) 완료 후 스프레드시트에 "버스정보", "버스인원", "팀별인원" 3개
   시트가 자동 생성됩니다.

   ⚠ 기사님 연락처는 개인정보 보호를 위해 코드(공개 저장소)에 넣지
     않고 빈 칸으로 시딩했습니다. 배포 후 앱의 "인원배치 → 관리자
     모드 → 버스 정보 수정"에서 직접 입력해 주세요(구글시트에만
     저장되고 공개 저장소에는 올라가지 않습니다).

   ⚠ 촬영팀·보수팀·소망택배팀 일부 인원, 안내팀·오병이어팀 일부
     인원수는 원본 이미지 판독 한계로 [확인필요]로 표시했습니다.
     원본 배치표와 대조해서 시트에서 직접 수정하거나, 앱의
     "인원배치 → 관리자 모드"에서 수정해 주세요.
   ⚠ 이름 폰트 색상(오렌지·녹색 등)은 이미지에서 정확히 판독하지
     못해 기본색으로 비워뒀습니다. 관리자 모드에서 각 이름 옆
     색상 선택 메뉴로 지정해 주세요.

3) "인원배치" 관리자 비밀번호는 Code.gs 14번째 줄
   var ADMIN_PW = '상주2026';
   으로 기본 지정되어 있습니다. 원하는 비밀번호로 바꾸고 싶으면
   이 값을 수정한 뒤 다시 저장(Ctrl+S)하고 재배포(STEP 3)하세요.

================================================================
  STEP 3. 웹 앱으로 배포
================================================================

1) Apps Script 편집기 우측 상단 [배포] → [새 배포]

2) 톱니바퀴(⚙) 아이콘 → 유형 선택 → "웹 앱"

3) 설정:
   - 설명: 상주아웃리치 v1
   - 다음 사용자로 실행: 나
   - 액세스 권한이 있는 사용자: 모든 사용자

4) [배포] 클릭 → 액세스 승인(계정 선택 → 고급 → 이동 → 허용)

5) 배포 완료 화면에 표시되는 "웹 앱 URL"을 복사
   (예: https://script.google.com/macros/s/AKfycb.../exec)

================================================================
  STEP 4. 앱에 서버 주소 연결
================================================================

1) index.html 을 웹호스팅(Netlify, GitHub Pages 등)에 올리거나
   스마트폰/PC에서 바로 열기

2) 앱 우측 상단 ⚙(설정) 버튼 클릭

3) STEP 3에서 복사한 웹 앱 URL을 붙여넣고 저장
   → 이후에는 각자 기기에 자동 저장되어 다시 입력할 필요 없음

4) "활동체크" 탭에서 팀을 선택하고 명단이 뜨는지 확인
5) "인원배치" 탭에서 버스배치·팀별 인원배치가 뜨는지 확인

★ "활동체크" 탭에 보수팀이 새로 추가되어 체크 항목이 9개→10개로
  바뀌었습니다. 이미 "초대자명단" 시트를 만든 적이 있다면 STEP 2의
  seedRoster를 한 번 더 실행해서 열 구성을 맞춰 주세요.
  ⚠ 재실행하면 그 시트의 기존 체크 기록은 모두 초기화됩니다.

================================================================
  사용 방법 요약
================================================================

- 안내팀: "안내팀" 선택 → 도착한 마을주민 이름 옆 [출석] 버튼 클릭
- 오병이어팀/꽃단장팀/발지압팀/추나요법팀/소망카페팀/소망놀이팀/
  보수팀/촬영팀/소망택배팀: 각 팀 선택 → 체험(방문)한 주민 이름 옆
  [방문] 버튼 클릭 → 팀별로 별도 기록되며 서로 겹치지 않습니다.
- 이름 옆에 9개 팀 전체의 체험 여부가 작은 배지로 표시되어, 어느 팀을
  선택해서 보든 그 주민이 이미 어떤 팀을 체험했는지 실시간으로 바로
  확인할 수 있습니다(중복 체험 방지 · 전체 팀 체험 유도).
- 여러 사람이 동시에 체크해도 모두 같은 스프레드시트에 실시간 반영됩니다.
- 상단 "↻ 새로고침"으로 다른 사람이 체크한 최신 상태를 불러올 수 있습니다.
- "⚙ 관리자" 모드로 들어오면(비밀번호 필요) 잘못 체크된 다른 팀의
  기록도 그 자리에서 바로 고칠 수 있습니다.

================================================================
  주의사항
================================================================

- 웹 앱 URL이 바뀌면(재배포 시 "새 버전"이 아니라 "새 배포"를 만든
  경우) 앱 설정에서 URL을 다시 입력해야 합니다. 가능하면 [배포 관리]
  → [새 버전]으로만 갱신하세요 (URL 유지).
- 초대자 명단에는 어르신들의 실명·연령이 포함되어 있습니다.
  스프레드시트 공유 권한을 필요한 사람에게만 열어 주세요.
- 정확한 팀별 인원 배치(5.배치 탭 수치)는 원본 배치표 인쇄 상태가
  좋지 않아 일부 재확인이 필요합니다. 현장 배치표와 대조해 주세요.
